# Brolis Game Translate — Marka dosyaları

## Renkler
- Koyu zemin: `#0A0E13`
- Ana vurgu / logo çizgisi: `#3EE6A0`
- İkincil vurgu / aktarım oku: `#B79CFF`
- Açık metin: `#F3F6FA`

## Yazı tipi
Arayüz ve wordmark için **Inter** veya **Manrope** önerilir. İkisi de SIL Open Font License (OFL) ile yayımlanır. Bu depoda font dosyası gömülü değildir; dağıtıma eklenirse ilgili fontun OFL lisans metni de pakete eklenmelidir. SVG yedeği `Arial, sans-serif` kullanır.

## Kullanım
- Uygulama simgesi `logo.svg` (ve onun 512 px PNG/ICO çıktıları) ile TV banner'ındaki aynı işareti kullanın.
- Kare simgenin dış zemini saydamdır; koyu yüzey üzerinde kullanın. İç konuşma balonu `#0A0E13` ile doldurulur, böylece simge açık zeminlerde de seçilir.
- Logo öğelerini yeniden renklendirmeyin, sıkıştırmayın, eğmeyin veya başka oyun/şirket markalarıyla birleştirmeyin.
- İsim ilk kullanımda **Brolis Game Translate**, kısa bildirimlerde **Brolis** olarak yazılmalıdır.
- Gerçek oyun, platform veya şirket logoları kullanılmaz ve taklit edilmez.

## Dosyalar
- `logo.svg`: saydam zeminli kare vektör simge
- `logo-512.png`: 512 × 512 PNG
- `logo.ico`: 16, 24, 32, 48, 64, 128 ve 256 px Windows simge boyutları
- `wordmark.svg`: simge ve yatay marka yazısı
- `tv-banner-320x180.png`: Android TV launcher banner'ı
