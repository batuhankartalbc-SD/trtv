# Brolis yazı tipleri

Bu klasördeki dosyalar Google Fonts deposundan, `main` dalının `06bfe0d62a98375cb09c942fa18e68bd32cff057` kaynak anlık görüntüsünden alınmıştır. Lisans metinleri font dosyalarıyla birlikte dağıtılır.

| Uygulama seçeneği | Dosya | Kaynak aile / kesim | Sürüm bilgisi | Lisans |
|---|---|---|---|---|
| Oyun stili (dar) | `condensed.ttf` | Barlow Semi Condensed SemiBold (600) | Google Fonts `main` anlık görüntüsü, 2026-11-22 | SIL Open Font License 1.1; `OFL-Barlow-SemiCondensed.txt` |
| Yuvarlak | `rounded.ttf` | Nunito değişken fontu, 700 ağırlık | Google Fonts `main` anlık görüntüsü, 2026-11-22 | SIL Open Font License 1.1; `OFL-Nunito.txt` |
| Sade | `clean.ttf` | Inter değişken fontu, 18 optik boyut / 600 ağırlık | Google Fonts `main` anlık görüntüsü, 2026-11-22 | SIL Open Font License 1.1; `OFL-Inter.txt` |

Google Fonts kaynakları:

- Barlow Semi Condensed: <https://github.com/google/fonts/tree/06bfe0d62a98375cb09c942fa18e68bd32cff057/ofl/barlowsemicondensed>
- Nunito: <https://github.com/google/fonts/tree/06bfe0d62a98375cb09c942fa18e68bd32cff057/ofl/nunito>
- Inter: <https://github.com/google/fonts/tree/06bfe0d62a98375cb09c942fa18e68bd32cff057/ofl/inter>

Bu aileler Türkçe Latin harflerini destekleyen Latin Extended karakter kapsamıyla dağıtılır. Uygulamadaki seçim anahtarları `default`, `condensed`, `rounded`, `clean` şeklindedir. `default`, dosya kullanmadan Android TV'deki `sans-serif-medium` kalın yazı tipini seçer.

## Marka kullanımı

- Fontları yalnızca Brolis Game Translate arayüzü ve altyazı çiziminde kullanın.
- Fontları oyunların özgün fontuymuş gibi tanıtmayın; oyun fontlarını kopyalamayın veya taklit etmeyin.
- Font dosyasını yeniden dağıtırken ilgili `OFL-*.txt` lisansını da koruyun. SIL OFL 1.1 koşulları geçerlidir.

## Yazı tipi önerisi

Marka dokümanları ve tanıtım görselleri için Inter önerilir. Inter SIL Open Font License (OFL) ile lisanslıdır; başka bir OFL fontu tercih edilirse lisans metni de dağıtıma eklenmelidir.
